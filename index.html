Com instal·lar i configurar un servidor DHCP a Ubuntu Server

Serveis en xarxes · 6 min

DHCP assigna adreces IP automàticament. Amb el paquet isc-dhcp-server pots muntar-ne un en pocs minuts. Abans cal una IP fixa al servidor, per exemple 192.168.10.1/24.

1. Instal·lació

sudo apt update
sudo apt install isc-dhcp-server

2. Interfície d'escolta

Edita /etc/default/isc-dhcp-server i indica la targeta de xarxa interna:

INTERFACESv4="enp0s8"

3. Àmbit d'adreces

A /etc/dhcp/dhcpd.conf defineix la xarxa, el rang, la passarel·la i el DNS:

subnet 192.168.10.0 netmask 255.255.255.0 {
  range 192.168.10.100 192.168.10.200;
  option routers 192.168.10.1;
  option domain-name-servers 192.168.10.1, 8.8.8.8;
  default-lease-time 600;
  max-lease-time 7200;
}
host impressora {
  hardware ethernet 08:00:27:aa:bb:cc;
  fixed-address 192.168.10.50;
}

El bloc host és una reserva: aquella MAC rebrà sempre la mateixa IP.

4. Reiniciar i comprovar

sudo systemctl restart isc-dhcp-server
sudo systemctl status isc-dhcp-server
cat /var/lib/dhcp/dhcpd.leases

Al client, executa sudo dhclient -v (Linux) o ipconfig /renew (Windows). Si falla, revisa que el rang pertanyi a la mateixa subxarxa que la interfície del servidor i que no hi hagi un altre DHCP a la xarxa.

Servidor DNS amb BIND9: creem una zona directa

Serveis en xarxes · 7 min

Un servidor DNS autoritatiu respon amb les adreces d'un domini que ell mateix gestiona. Farem la zona smx.local.

1. Instal·lació

sudo apt install bind9 bind9utils dnsutils

2. Declarar la zona

A /etc/bind/named.conf.local:

zone "smx.local" {
  type master;
  file "/etc/bind/db.smx.local";
};

3. Fitxer de zona

$TTL 86400
@   IN SOA ns1.smx.local. admin.smx.local. (
        1 3600 900 604800 86400 )
@   IN NS  ns1.smx.local.
ns1 IN A   192.168.10.1
web IN A   192.168.10.20
www IN CNAME web

Cada vegada que canviïs la zona, augmenta el número de sèrie (el primer valor del SOA).

4. Validar i provar

sudo named-checkconf
sudo named-checkzone smx.local /etc/bind/db.smx.local
sudo systemctl restart bind9
dig @192.168.10.1 www.smx.local

Si dig torna l'adreça de web, la zona funciona. L'error més habitual és oblidar el punt final als noms complets (ns1.smx.local.).

FTP segur amb vsftpd: usuaris enjaulats i xifratge

Serveis en xarxes · 6 min

vsftpd és un servidor FTP lleuger i segur per defecte. Veurem com limitar cada usuari al seu directori i com activar TLS, ja que FTP clàssic envia les contrasenyes en text pla.

sudo apt install vsftpd
sudo cp /etc/vsftpd.conf /etc/vsftpd.conf.bak

Configuració bàsica

anonymous_enable=NO
local_enable=YES
write_enable=YES
chroot_local_user=YES
allow_writeable_chroot=YES
pasv_min_port=40000
pasv_max_port=40100
ssl_enable=YES
rsa_cert_file=/etc/ssl/certs/ssl-cert-snakeoil.pem
rsa_private_key_file=/etc/ssl/private/ssl-cert-snakeoil.key

chroot_local_user tanca cada usuari a la seva carpeta. El rang passiu cal obrir-lo també al tallafocs. El certificat snakeoil només serveix per proves; en producció usa un de real.

sudo adduser alumne
sudo systemctl restart vsftpd
sudo ufw allow 21/tcp
sudo ufw allow 40000:40100/tcp

Prova-ho amb FileZilla triant «FTP sobre TLS explícit». Si necessites res més robust, considera SFTP, que ja ve amb SSH.

Tallafocs a Linux amb ufw: regles bàsiques pas a pas

Seguretat · 5 min

ufw (Uncomplicated Firewall) simplifica iptables. La idea és denegar tot el trànsit entrant i obrir només els serveis necessaris.

sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp
sudo ufw allow from 192.168.10.0/24 to any port 53
sudo ufw enable
sudo ufw status numbered

Important: permet SSH (port 22) abans d'activar ufw si treballes per remot, o et quedaràs fora del servidor.

Esborrar i limitar

sudo ufw delete 3
sudo ufw limit 22/tcp

limit bloqueja temporalment IP que facin massa intents de connexió, útil contra atacs de força bruta. Per veure què es bloqueja, mira /var/log/ufw.log després d'activar sudo ufw logging on.

Crear una VPN amb WireGuard entre dos equips

Seguretat · 8 min

WireGuard és una VPN moderna, ràpida i amb poc codi. Cada equip té una parella de claus i només cal intercanviar les claus públiques.

sudo apt install wireguard
wg genkey | tee privada.key | wg pubkey > publica.key

Servidor: /etc/wireguard/wg0.conf

[Interface]
Address = 10.8.0.1/24
ListenPort = 51820
PrivateKey = (clau privada del servidor)

[Peer]
PublicKey = (clau pública del client)
AllowedIPs = 10.8.0.2/32

Client

[Interface]
Address = 10.8.0.2/24
PrivateKey = (clau privada del client)

[Peer]
PublicKey = (clau pública del servidor)
Endpoint = IP_DEL_SERVIDOR:51820
AllowedIPs = 10.8.0.0/24
PersistentKeepalive = 25
sudo wg-quick up wg0
sudo wg show
ping 10.8.0.1

Recorda obrir el port UDP 51820 al tallafocs. Si vols que tot el trànsit del client passi pel túnel, posa AllowedIPs = 0.0.0.0/0 i activa l'IP forwarding al servidor.

Subxarxes sense por: màscares, CIDR i com calcular-les

Fonaments · 6 min

Una adreça IPv4 té 32 bits. La màscara indica quants són de xarxa i quants d'equip. Amb /24, 24 bits són de xarxa i en queden 8 per a equips.

Fórmula clau

Equips útils = 2bits d'equip − 2 (es resten l'adreça de xarxa i la de difusió).

  • /24 → 256 adreces, 254 equips, màscara 255.255.255.0
  • /25 → 128 adreces, 126 equips, màscara 255.255.255.128
  • /26 → 64 adreces, 62 equips, màscara 255.255.255.192
  • /30 → 4 adreces, 2 equips (enllaços punt a punt)

Exemple

Vols dividir 192.168.1.0/24 en 4 subxarxes. Necessites 2 bits més, així que passes a /26. Les subxarxes seran 192.168.1.0, .64, .128 i .192, cadascuna amb 62 equips. A la primera, el rang útil és 192.168.1.1–192.168.1.62 i la difusió és 192.168.1.63.

Truc: el «salt» entre subxarxes és 256 menys el valor de l'últim octet de la màscara (256 − 192 = 64).

Ordres imprescindibles per diagnosticar problemes de xarxa

Fonaments · 5 min

Quan «no hi ha Internet», segueix sempre el mateix ordre, de dins cap a fora:

  1. Targeta i IP: ip a (Linux) o ipconfig /all (Windows). Si tens una 169.254.x.x, el DHCP no ha respost.
  2. Passarel·la: ip route i ping 192.168.10.1.
  3. Sortida a Internet per IP: ping 8.8.8.8.
  4. Resolució de noms: nslookup pereizel.com o dig pereizel.com. Si el pas 3 va bé i aquest falla, és un problema de DNS.
  5. Camí: traceroute 8.8.8.8 (tracert a Windows) mostra on s'atura el trànsit.
  6. Ports i serveis: ss -tulpn llista què escolta a cada port.

Anotar el que funciona a cada pas és la manera més ràpida de saber on és el problema.

Model OSI i TCP/IP: les capes explicades fàcil

Fonaments · 5 min

Les xarxes es dissenyen per capes: cadascuna fa una feina i confia en la de sota. El model OSI en té 7; TCP/IP, 4.

  • Física i enllaç (1-2): cables, Wi-Fi, adreces MAC, commutadors.
  • Xarxa (3): adreces IP i encaminadors. Eines: ping, traceroute.
  • Transport (4): TCP (fiable, amb connexió) i UDP (ràpid, sense garanties). Aquí viuen els ports.
  • Aplicació (5-7): HTTP, DNS, DHCP, FTP, SSH.

Utilitat pràctica: si no fa ping, mira les capes 1-3; si fa ping però no carrega la web, el problema és de la 4 o superior (port tancat, DNS, servei aturat).

IP fixa a Ubuntu Server amb Netplan

Fonaments · 4 min

Els servidors han de tenir IP estàtica. A Ubuntu es configura amb YAML a /etc/netplan/00-config.yaml (el nom pot variar):

network:
  version: 2
  ethernets:
    enp0s3:
      dhcp4: false
      addresses: [192.168.10.1/24]
      routes:
        - to: default
          via: 192.168.10.254
      nameservers:
        addresses: [8.8.8.8, 1.1.1.1]
sudo netplan try
sudo netplan apply
ip a show enp0s3

YAML és molt sensible als espais: usa només espais, mai tabuladors. netplan try desfà els canvis si no confirmes, així no et quedes sense xarxa.

SSH segur: claus públiques i fail2ban

Seguretat · 6 min

SSH és la porta d'entrada a qualsevol servidor Linux i la més atacada. Tres mesures bàsiques:

1. Entrar amb clau en lloc de contrasenya

ssh-keygen -t ed25519
ssh-copy-id usuari@192.168.10.1

2. Enduriment a /etc/ssh/sshd_config

PermitRootLogin no
PasswordAuthentication no
MaxAuthTries 3
sudo sshd -t && sudo systemctl restart ssh

Prova la clau en una sessió nova abans de tancar l'actual.

3. Bloquejar atacants amb fail2ban

sudo apt install fail2ban
sudo systemctl enable --now fail2ban
sudo fail2ban-client status sshd

Per defecte bloqueja una IP després de diversos intents fallits. Canviar el port 22 només redueix soroll als registres; no és seguretat real.

Còpies de seguretat amb rsync i cron

Fonaments · 5 min

Regla 3-2-1: tres còpies, en dos suports diferents, una fora de lloc. rsync copia només el que ha canviat.

rsync -avh --delete /srv/dades/ /mnt/backup/dades/
rsync -avz /srv/dades/ usuari@192.168.10.5:/backup/dades/

-a conserva permisos i dates, -z comprimeix, --delete esborra al destí el que ja no existeix a l'origen. Prova sempre amb -n (simulació) primer.

Automatitzar cada nit a les 2:30

crontab -e
30 2 * * * rsync -a --delete /srv/dades/ /mnt/backup/dades/ >> /var/log/backup.log 2>&1

Una còpia que no s'ha provat de restaurar no és una còpia: comprova-ho cada cert temps.

Servidor web Apache i hosts virtuals

Serveis en xarxes · 6 min 
sudo apt install apache2
sudo mkdir -p /var/www/smx/public
echo "<h1>Hola SMX</h1>" | sudo tee /var/www/smx/public/index.html

Crea /etc/apache2/sites-available/smx.conf:

<VirtualHost *:80>
  ServerName web.smx.local
  DocumentRoot /var/www/smx/public
  ErrorLog ${APACHE_LOG_DIR}/smx-error.log
</VirtualHost>
sudo a2ensite smx.conf
sudo apache2ctl configtest
sudo systemctl reload apache2

Amb diversos VirtualHost i noms diferents pots servir moltes webs des d'una sola IP. Si hi ha un DNS propi, afegeix un registre A cap al servidor; si no, usa el fitxer hosts del client. Els errors es veuen a /var/log/apache2/.

Samba: compartir carpetes entre Linux i Windows

Serveis en xarxes · 6 min 
sudo apt install samba
sudo mkdir -p /srv/compartit
sudo chown -R :alumnes /srv/compartit
sudo chmod 2770 /srv/compartit

Afegeix al final de /etc/samba/smb.conf:

[compartit]
  path = /srv/compartit
  valid users = @alumnes
  read only = no
  create mask = 0660
sudo smbpasswd -a alumne
testparm
sudo systemctl restart smbd

Des de Windows, obre \\192.168.10.1\compartit. L'usuari ha d'existir al sistema Linux i tenir contrasenya Samba (smbpasswd és independent de la del sistema). Permisos: sempre mana el més restrictiu entre els de Samba i els del sistema de fitxers.

Captura de trànsit amb tcpdump: veure què passa al cable

Seguretat · 5 min

tcpdump captura paquets des del terminal i és ideal per veure el DHCP, el DNS o un handshake TCP.

sudo tcpdump -i enp0s3 -n
sudo tcpdump -i enp0s3 port 53
sudo tcpdump -i enp0s3 host 192.168.10.20 and tcp port 80
sudo tcpdump -i enp0s3 -w captura.pcap

L'últim desa un fitxer que pots obrir amb Wireshark. Per veure DHCP: sudo tcpdump -i enp0s3 -n port 67 or port 68; hi veuràs Discover, Offer, Request i Ack.

Al TCP, busca els indicadors [S] (SYN), [S.] (SYN-ACK) i [.] (ACK): és la salutació de tres passos. Un SYN sense resposta indica un tallafocs que descarta, i un [R.] un port tancat. Captura només a xarxes pròpies o amb permís.
